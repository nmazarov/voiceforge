# VoiceForge — быстрый старт на VPS

## 1. Скачать проект

```bash
git clone https://github.com/nmazarov/voiceforge.git
cd voiceforge
chmod +x install.sh
./install.sh
```

После этого откроется интерактивная панель VoiceForge Server Manager.

В дальнейшем панель запускается из любой папки одной командой:

```bash
voiceforge
```

## Главное меню

- `1` — Установить / первичная настройка
- `2` — Обновить до последней версии из GitHub
- `3` — Запустить сервер
- `4` — Остановить сервер
- `5` — Перезапустить сервер
- `6` — Посмотреть статус и адреса
- `7` — Посмотреть последние логи
- `8` — Изменить настройки
- `9` — Создать резервную копию
- `10` — Удалить контейнеры без удаления данных

При первом выборе «Установить» панель автоматически создаёт `.env`, генерирует JWT и LiveKit-секреты, определяет публичный IP VPS, собирает Docker-образы и запускает сервер.

## Firewall

Для тестового VPS откройте:

```text
TCP 3001
TCP 7881
UDP 50000-50100
```

После запуска web-клиент будет доступен по адресу:

```text
http://SERVER_IP:3001
```

## Обновление

Вместо ручного `git pull` просто запустите:

```bash
voiceforge
```

и выберите `2. Обновить до последней версии`.

`.env`, SQLite-база и пользовательские данные при обновлении сохраняются.
