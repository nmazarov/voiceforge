# VoiceForge 🎙️💬

**VoiceForge** — мощная self-hosted альтернатива Discord для приватного общения с нативными десктопными клиентами, кристально чистым звуком, продвинутым шумоподавлением и интерактивным чатом.

---

## ✨ Ключевые возможности

### 🎧 Профессиональный звук и Noise Gate
* **Активация по голосу (VAD & Noise Gate)**: тонкая настройка порога чувствительности и автоматический режим. Фоновый шум, кулеры и дыхание полностью отсекаются с мягким таймером затухания.
* **Регулировка усиления микрофона 0–200%**: чистый и громкий голос даже на тихих гарнитурах.
* **Тестирование микрофона и «Слушать себя» (Loopback)**: динамический VU-метр с визуальным маркером порога срабатывания и возможностью услышать работу шумодава в своих наушниках перед входом в канал.
* **Аппаратные фильтры**: встроенное шумоподавление, эхоподавление и АРУ (автоматическая регулировка усиления).

### 🖥️ Интерфейс и боковая панель в стиле Discord
* **Сворачиваемые категории каналов**: удобные блоки `▼ ТЕКСТОВЫЕ КАНАЛЫ` и `▼ ГОЛОСОВЫЕ КАНАЛЫ` со счётчиками и мгновенным скрытием по клику.
* **Вложенные участники голосовых комнат**: говорящие пользователи выделяются пульсирующим зелёным кольцом прямо в списке каналов.
* **Нижняя панель пользователя (Discord User Panel)**: быстрый доступ к микрофону (`🎙️`/`🔇`), звуку (`🎧`/`🔇`), настройкам (`⚙️`) и статусу аккаунта.
* **Плашка голосового статуса и пинг**: отображение текущего голосового канала, задержки сети в реальном времени (🟢 <60ms, 🟡 <150ms) и кнопка быстрого отключения `📞✕`.

### 💬 Интерактивный чат и Markdown
* **Полноценное форматирование**: `**жирный**`, `*курсив*`, `~~зачёркнутый~~`, `` `код` ``, многострочные блоки кода с подсветкой и цитаты `> `.
* **Спойлеры**: скрытый текст `||тайный текст||`, открывающийся по клику.
* **Реакции-эмодзи**: плашки реакций под сообщениями с живой синхронизацией через WebSocket и меню быстрых реакций при наведении.
* **Ответы и цитирование**: дуга цитирования `┌─ @пользователь` и предпросмотр ответа в поле ввода.
* **Скриншоты и вложения**: вставка изображений напрямую из буфера обмена (`Ctrl+V`) и прикрепление файлов до 5 МБ.

### 🔒 Сохранение сервера и сессии
* IP-адрес или домен сервера, а также токен входа сохраняются локально. Вводить данные нужно **только один раз при первом запуске** — дальше приложение мгновенно открывается в рабочих каналах.

## 🏗️ Архитектура

```text
voiceforge/
├── server/   # Только VPS: API (Fastify), SQLite, WebSocket Gateway, LiveKit, Docker
└── client/   # Десктоп-клиент: Electron + React 19 + TypeScript + Vite (Windows / Linux)
```

Сервер и десктопный клиент полностью независимы: пользователь устанавливает легковесное нативное приложение VoiceForge и подключается к своему серверу.

---

## 🚀 Развёртывание сервера (VPS)

Рекомендованные параметры: **4 vCPU / 8 GB RAM / 1 Gbps** (Ubuntu / Debian).

```bash
git clone https://github.com/nmazarov/voiceforge.git
cd voiceforge/server
chmod +x install.sh
sudo ./install.sh
```

Управление сервером осуществляется одной командой:

```bash
voiceforge
```

Панель администрирования доступна по адресу `http://<IP_СЕРВЕРА>/admin`.

## 💻 Сборка клиентов

### Windows

```powershell
cd client
npm install
npm run build:windows
```

Результат: готовый инсталлятор `release/VoiceForge-Setup-1.1.0.exe`.

Для портативной версии:
```powershell
npm run build:windows:portable
```

### Linux (Ubuntu, Debian, Fedora, Arch)

```bash
cd client
npm install
npm run build:linux
```

Результаты: `.deb` пакет для систем Debian/Ubuntu и универсальный `VoiceForge-1.1.0-x86_64.AppImage`.
