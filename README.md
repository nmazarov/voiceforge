# VoiceForge 🎙️💬

**VoiceForge** — мощная self-hosted альтернатива Discord для приватного общения с нативными десктопными клиентами, кристально чистым звуком, продвинутым шумоподавлением (Noise Gate) и интерактивным чатом.

## ⚡ Быстрый старт: Запуск сервера в 1 команду

Для запуска серверной части на любом чистом VPS (Ubuntu / Debian) достаточно выполнить одну команду:

```bash
curl -sSL https://raw.githubusercontent.com/nmazarov/voiceforge/main/install.sh | sudo bash
```

*Или внутри клонированного репозитория:*
```bash
sudo ./install.sh
```

### Что сделает скрипт автоматически:
1. Проверит и установит Docker и Docker Compose (если они отсутствуют).
2. Сгенерирует надежные криптографические ключи (`.env`, `livekit.yaml`, JWT, Admin Key).
3. Настроит порты в фаерволе (UFW).
4. Запустит контейнеры VoiceForge API и медиа-сервера WebRTC (LiveKit).
5. **Выведет в терминал готовые подсказки**:
   - Адрес сервера для вставки в приложение (`http://<IP_СЕРВЕРА>:3001`).
   - Ссылку на панель управления (`http://<IP_СЕРВЕРА>:3001/admin`).
   - Логин и пароль владельца (`owner`).
   - Ссылки на скачивание клиентов под Windows и Linux.

## 📊 Подбор VPS: характеристики под количество человек

Медиа-сервер VoiceForge построен на базе современной SFU-архитектуры (WebRTC / LiveKit). Аудиопотоки передаются с высоким качеством через кодек Opus, а видеостриминг экрана оптимизируется под скорость сети каждого зрителя.

Используйте таблицу ниже для выбора подходящего тарифа VPS:

| Масштаб | Одновременно в голосе | Одновременных стримов экрана | Рекомендуемые характеристики VPS | Канал связи | Примерная стоимость |
| :--- | :---: | :---: | :--- | :---: | :---: |
| **Для друзей / Малый** | **до 15–20 чел.** | 1–2 стрима (720p / 1080p 30fps) | **1–2 vCPU / 2 GB RAM** | 100 Mbps | ~200–400 ₽/мес. ($3–$5) |
| **Клан / Команда / Средний** | **до 50–70 чел.** | 3–5 стримов (1080p 60fps) | **2–4 vCPU / 4–8 GB RAM** | 500 Mbps – 1 Gbps | ~500–900 ₽/мес. ($7–$12) |
| **Большое сообщество** | **до 150–250 чел.** | 5–10 стримов (1080p 60fps) | **4–8 vCPU / 8–16 GB RAM** | 1 Gbps | ~1200–2500 ₽/мес. ($15–$30) |
| **Enterprise / Киберспорт** | **500+ чел.** | 10+ стримов Full HD | **8–16 vCPU / 16–32 GB RAM** | 1–10 Gbps | от 3000 ₽/мес. ($40+) |

### 🌐 Сетевые требования:
* **Публичный IP-адрес** (белый IPv4).
* **Сетевые порты** (скрипт установщика открывает их автоматически):
  * `TCP 3001` — основной API сервера, веб-клиент, админка и WebSocket сообщений.
  * `TCP 7880, 7881` — сигналинг WebRTC и резервный транспорт LiveKit.
  * `UDP 50000–50100` — медиа-потоки аудио и видео без задержек.

## 🛠️ Управление сервером на VPS

После установки сервер доступен через глобальную системную команду `voiceforge`:

```bash
voiceforge          # Открыть интерактивное псевдографическое меню управления
voiceforge status   # Проверить статус работы контейнеров и сетевые адреса
voiceforge logs     # Смотреть логи в реальном времени
voiceforge restart  # Перезапустить сервер
voiceforge stop     # Остановить сервер
voiceforge start    # Запустить сервер
voiceforge backup   # Создать резервную копию конфигурации и базы данных
```

## ✨ Возможности приложения

### 🎧 Профессиональный звук и Noise Gate
* **Активация по голосу (VAD & Noise Gate)**: тонкая настройка порога чувствительности и авто-режим. Фоновый шум, кулеры и дыхание полностью отсекаются с мягким спадом затухания.
* **Регулировка усиления микрофона 0–200%**: чистый и громкий голос даже на тихих микрофонах.
* **Тестирование микрофона и «Слушать себя» (Loopback)**: динамический VU-метр с маркером границы срабатывания и проверка работы шумодава в своих наушниках.
* **Аппаратные фильтры**: встроенное шумоподавление, эхоподавление и АРУ (автоматическая регулировка усиления).

### 🖥️ Интерфейс и боковая панель в стиле Discord
* **Сворачиваемые категории каналов**: удобные блоки `▼ ТЕКСТОВЫЕ КАНАЛЫ` и `▼ ГОЛОСОВЫЕ КАНАЛЫ` со счётчиками и плавным скрытием по клику.
* **Вложенные участники голосовых комнат**: говорящие пользователи выделяются пульсирующим зелёным кольцом прямо в списке каналов.
* **Нижняя панель пользователя (Discord User Panel)**: быстрый доступ к микрофону (`🎙️`/`🔇`), звуку (`🎧`/`🔇`), настройкам (`⚙️`) и статусу аккаунта.
* **Плашка голосового статуса и пинг**: отображение текущего голосового канала, задержки сети в реальном времени (🟢 <60ms, 🟡 <150ms) и кнопка быстрого отключения `📞✕`.

### 💬 Интерактивный чат и Markdown
* **Полноценное форматирование**: `**жирный**`, `*курсив*`, `~~зачёркнутый~~`, `` `код` ``, многострочные блоки кода с подсветкой и цитаты `> `.
* **Спойлеры**: скрытый текст `||тайный текст||`, открывающийся по клику.
* **Реакции-эмодзи**: плашки реакций под сообщениями с живой синхронизацией через WebSocket и меню быстрых реакций при наведении.
* **Ответы и цитирование**: дуга цитирования `┌─ @пользователь` и предпросмотр ответа в поле ввода.
* **Скриншоты и вложения**: вставка изображений напрямую из буфера обмена (`Ctrl+V`) и прикрепление файлов до 5 МБ.

### 🔒 Сохранение сервера и сессии
* IP-адрес или домен сервера, а также токен входа сохраняются локально. Вводить данные нужно **только один раз при первом запуске** — дальше приложение мгновенно открывается в рабочих каналах.

## 🏗️ Архитектура

```text
voiceforge/
├── server/   # Только VPS: API (Fastify), SQLite, WebSocket Gateway, LiveKit, Docker
└── client/   # Десктоп-клиент: Electron + React 19 + TypeScript + Vite (Windows / Linux)
```

Сервер и десктопный клиент полностью независимы: пользователь устанавливает легковесное нативное приложение VoiceForge и подключается к своему серверу.

## 💻 Сборка десктоп-клиентов

### Windows

```powershell
cd client
npm install
npm run build:windows
```

Результат: готовый инсталлятор `release/VoiceForge-Setup-1.1.0.exe`.

Для портативной версии:
```powershell
npm run build:windows:portable
```

### Linux (Ubuntu, Debian, Fedora, Arch)

```bash
cd client
npm install
npm run build:linux
```

Результаты: `.deb` пакет для систем Debian/Ubuntu и универсальный `VoiceForge-1.1.0-x86_64.AppImage`.
