# VoiceForge Brand / UI Concept

## Идея

VoiceForge должен ощущаться не как копия Discord, а как быстрый self-hosted gaming voice tool: технологичный, приватный и лёгкий.

## Логотип

Основной знак — металлическая буква **V**, собранная из двух направленных внутрь лезвий/звуковых волн. Он одновременно читается как Voice, соединение двух пользователей и щит приватного сервера.

Файл: `client/assets/logo.svg`.

- Danger / disconnect: `#EF4444`

## UI

Основная компоновка: узкая product rail → сервер/каналы → рабочая область → участники. Голосовая комната превращается в отдельный visual stage с карточками участников, индикаторами речи и screen-share media. Экран подключения использует крупный V-знак и показывает self-hosted идею до авторизации.

Windows и Linux используют идентичную дизайн-систему; различается только платформенная упаковка.
